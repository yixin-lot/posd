# 部署与运维

## 一、安装（Windows，最常见）

1. 下载 `posd_windows_amd64.exe`（约 11 MB，单文件，无需安装 Go/Node）；
2. 放到一个**固定目录**，例如 `D:\pos\`；
3. 双击运行，或建快捷方式：

```powershell
.\posd.exe --addr 127.0.0.1:8080 --db D:\pos\pos.db --printer POS-58
```

4. 浏览器打开 <http://127.0.0.1:8080>，首次进入是初始化向导（店名 → 行业模板 → 打印测试 → 完成）；
5. 默认管理员：`admin` / `1234`，**装完立刻改 PIN**。

### 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--addr` | `127.0.0.1:8080` | 监听地址；要让收银平板访问改 `0.0.0.0:8080` |
| `--db` | `pos.db` | 数据库路径（建议放非系统盘） |
| `--printer` | 空 | 默认打印机（Windows 队列名） |
| `--backup-keep` | 7 | 保留几份日备份 |
| `--no-backup` | false | 关闭自动备份（不建议） |

## 二、打印

### 小票打印机（58mm / 80mm）

1. 装好 Windows 驱动，在「设备和打印机」里确认队列名（例如 `POS-58`）；
2. 用队列名启动 `--printer POS-58`，或在设置页填「小票打印机」；
3. 设置页点「打印测试」，出纸即成功。

### 网口打印机（推荐用于后厨）

厨房打印机通常不在收银机旁边。支持 **ESC/POS raw 直连**，不用装驱动：

```
tcp://192.168.1.50:9100
```

- 打印机需设置**固定 IP**（路由器里做 DHCP 保留），否则重启后 IP 变了就出不了单；
- 默认端口 9100（多数热敏网口打印机出厂即是）；
- 设置页「档口」的打印机字段填这个地址即可；填 Windows 队列名（如 `POS-58`）则走系统队列；
- 连通性验证：`POST /pos/v1/printers/test {"target":"tcp://192.168.1.50:9100"}`，返回 `ok` 与提示。

失败不会卡住收银：打印任务进队列重试，多次失败后标记「待重打」。

### 后厨档口（可多台）

设置页 → 后厨档口：

| 字段 | 说明 |
|---|---|
| 档口名 | 例如「水吧」「热菜」 |
| 打印机 | Windows 队列名 |
| 类目 | 逗号分隔；**留空 = 该档口收全部菜品** |

下单时按类目分单，每个档口各出一张（不印价格，带桌号）。

**一个档口都没配时**，回落到设置里的单台「后厨打印机」——老配置不会失效。

## 三、备份与恢复

- 默认每天自动 `VACUUM INTO` 一份快照，保留 7 份；
- 手动备份：设置页「立即备份」，或
  ```powershell
  curl -X POST http://127.0.0.1:8080/pos/v1/admin/backup -H "Authorization: Bearer <token>"
  ```
- 恢复：**停掉 posd → 用备份文件覆盖 `pos.db` → 重启**。

> 建议：把备份目录同步到网盘/U 盘。**数据库和备份放同一块盘，等于没有备份。**

## 四、升级

1. 停 posd（任务管理器结束进程即可，SQLite 不会损坏）；
2. 备份 `pos.db`；
3. 用新 exe 覆盖旧 exe（**不要删 `pos.db`**）；
4. 启动，迁移会自动执行（`V1`→最新）。

**降级不支持**：迁移只向前。要回退必须还原备份。

## 五、排障

| 现象 | 排查 |
|---|---|
| 打不开页面 | 端口占用：`Get-NetTCPConnection -LocalPort 8080`；换 `--addr 127.0.0.1:8081` |
| 出不了纸 | 队列名拼错 / 打印机脱机 / 不是 ESC/POS 打印机；先跑「打印测试」 |
| 小票中文乱码 | 打印机不支持 GBK；换机型或在驱动里设字符集 |
| 二维码/条码打成乱码 | 属于极老固件不支持 ESC/POS `GS ( k` / `GS k`；常规 USB/网口机默认支持，先换一台同型号验证，仍不行则关闭设置里的 `receipt_qr_text` |
| 后厨不出单 | 档口类目与商品类目不一致；或该菜品类目为空 |
| 提示「会员已停用」 | 会员中心里启用该会员 |
| 启动报 database is locked | 有另一个 posd 实例在跑，结束它 |

日志在启动目录的 `pos.log`（或控制台输出）。

## 六、多端访问

收银平板/手机连同一局域网，访问 `http://<收银机IP>:8080`。

- 需要 `--addr 0.0.0.0:8080`；
- **当前是 HTTP 明文**，只建议在店内可信网络使用；跨网访问请自行加 TLS 反向代理（Caddy/Nginx）。

## 七、Linux / macOS

```bash
./posd_linux_amd64 --addr 0.0.0.0:8080 --db /var/lib/pos/pos.db
```

Linux 打印走 `lp` 队列时，把 `--printer` 设为队列名；没有 spooler 时可用 `--printer file` 把字节写入 `print.bin`（调试用）。
